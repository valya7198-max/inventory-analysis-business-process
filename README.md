# Информационная система анализа запасов регионального дистрибьютора автозапчастей (на базе Loginom и Python)

## 📌 Бизнес-контекст и практическая направленность
Региональные дистрибьюторы автозапчастей оперируют огромной номенклатурой товаров с нестабильным спросом, наличием тысяч аналогов и заменителей деталей. Ручной анализ данных в Excel приводит к двум критическим проблемам для бизнеса:
1. **Дефицит (Out-of-stock):** упущенная прибыль из-за отсутствия ходовых деталей на складе.
2. **Затоваривание (Overstock):** «замораживание» оборотных средств в неликвидных и избыточных остатках.

**Цель проекта:** Разработать автоматизированную систему сквозного анализа складских запасов и продаж для оптимизации закупочной деятельности, снижения издержек и автоматизации формирования управленческой отчетности.

---

## 🛠 Технологический стек и архитектура
* **Аналитическая платформа:** Loginom Community Edition (ETL, обработка данных, построение моделей)
* **Язык программирования:** Python (реализация кастомной логики фильтрации и генерация Excel-отчетов с помощью pandas/openpyxl в модуле отчетности)
* **Инструменты моделирования:** Business Studio, Process Modeler (диаграммы AS-IS / TO-BE, BPMN)
* **Среда хранения данных:** Microsoft Excel (*.xlsx, *.csv плоские таблицы-выгрузки из 1С)

## 🚀 Ключевой функционал и реализованные алгоритмы

### 1. Сквозной ETL-процесс (Предобработка данных)
Спроектирована и реализована логическая модель объединения разрозненных сущностей (`Номенклатура`, `Текущие остатки`, `Продажи-шапка` и `Продажи-позиции`) по ключевым полям (`Product_ID`, `Sale_ID`). Настроена автоматическая очистка данных от дубликатов, аномалий и обработка `NULL`-значений.


### 2. Продвинутая классификация ассортимента (ABC/XYZ + Кластеризация)
* **ABC/XYZ-анализ:** Автоматическое разделение всей номенклатуры на 9 групп. Выделена группа **AX** (стабильная база, приносящая основной доход) и группа **CZ** (редкий спрос / потенциальный неликвид).
* **Кластеризация (алгоритм k-means):** Товарная матрица автоматически разбита на 5 смысловых кластеров: *«Стабильная база»*, *«Мелкие расходники»*, *«Наиболее прибыльные»*, *«Залежавшиеся»* и *«Прибыльная середина»*. Это позволяет применять дифференцированные стратегии управления к разным группам автозапчастей.

### 3. Прогнозирование спроса и расчет нормы запасов
На базе анализа временных рядов в Loginom выстроены прогнозные модели:
* Прогноз спроса в **количественном выражении** (физический объем для планирования загрузки склада).
* Прогноз продаж в **денежном выражении** (выручка для финансового планирования).
* **Расчет нормы запасов:** Автоматически вычисляются *средний спрос*, *целевой остаток* (с учетом страхового запаса), *рекомендуемый объем заказа* и *приоритет пополнения*.

### 4. Data Mining (Поиск ассоциативных правил)
Реализован алгоритм поиска частых наборов для выявления **популярных товарных пар** (совместно приобретаемые автозапчасти, например, "Фильтр воздушный + Фильтр масляный"). Помогает оптимизировать кросс-маркетинг и комплектовать заказы на складе быстрее.

### 5. Автоматизированная генерация отчетов (Python)
Разработан кастомный скрипт на Python внутри экосистемы Loginom, который автоматически консолидирует результаты анализа и выгружает итоговый структурированный Excel-отчет для топ-менеджмента, состоящий из 4 функциональных листов:
1. Проблемные позиции (дефицит/излишек)
2. Товары к срочному пополнению
3. Излишки и низкий спрос
4. Сводная панель показателей (Dashboard)
